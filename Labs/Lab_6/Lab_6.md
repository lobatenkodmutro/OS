> **5.1. Яке призначення команд `tar`, `xz`, `zip`, `bzip`, `gzip`? Короткий опис і основні параметри. Як їх встановити.**

**1. Команда `tar` (Tape Archive)**

`tar` — архіватор, основне завдання якого полягає у збиранні багатьох файлів і каталогів в один файл (так зване "tarball"). Сама по собі вона не стискає дані, але вміє викликати зовнішні утиліти стиснення (`gzip`, `bzip2`, `xz`). При цьому повністю зберігається структура каталогів, права доступу та інші метадані.

Основні параметри:

`-c` — створити новий архів.  
`-x` — розпакувати архів.  
`-v` — виводити детальну інформацію про процес роботи.  
`-f` — вказати ім'я файлу архіву (завжди зазначається перед назвою файлу).  
`-z` — стиснення через `gzip` (розширення `.tar.gz`).  
`-j` — стиснення через `bzip2` (розширення `.tar.bz2`).  
`-J` — стиснення через `xz` (розширення `.tar.xz`).

**2. Команда `gzip` (GNU zip)**

Популярна утиліта для швидкого стиснення файлів на основі алгоритму DEFLATE. Дуже поширена в Linux через низьке споживання ресурсів, хоча ступінь стиснення поступається новішим аналогам. Після стиснення оригінальний файл замінюється файлом із розширенням `.gz`.

Основні параметри:

`-d` — розпакувати файл (аналог `gunzip`).  
`-k` — зберегти оригінальний файл після операції.  
`-r` — рекурсивно стиснути всі файли у вказаному каталозі (кожен окремо).  
`-1` ... `-9` — рівень стиснення (1 — швидко, 9 — максимально щільно).

**3. Команда `bzip2`**

Забезпечує вищий ступінь стиснення, ніж `gzip`, за рахунок алгоритму блочного сортування Барроуза-Вілера. Результуючі файли мають розширення `.bz2`. Процес виконується повільніше та вимагає більше оперативної пам'яті.

Основні параметри:

`-d` — розпакувати файл (аналог `bunzip2`).  
`-k` — зберегти оригінальний файл.  
`-1` ... `-9` — розмір блоку пам'яті, що використовується при стисненні.

**4. Команда `xz`**

Сучасний інструмент стиснення на основі алгоритму LZMA2. Забезпечує найвищий ступінь стиснення серед розглянутих утиліт, створюючи файли `.xz`. Водночас процес є найбільш ресурсоємним — потребує значного часу та процесорних ресурсів. Розпакування при цьому відбувається відносно швидко.

Основні параметри:

`-d` — розпакувати файл (аналог `unxz`).  
`-k` — зберегти оригінальний файл.  
`-0` ... `-9` — рівень стиснення (стандартне значення — 6).  
`-e` — екстремальний режим (максимальна компресія, але дуже повільно).

**5. Команда `zip`**

На відміну від `gzip` чи `xz`, `zip` одночасно архівує і стискає кілька файлів. Формат `.zip` є кросплатформним стандартом, прийнятим у Windows та macOS, тому ця команда зручна при обміні файлами між різними ОС.

Основні параметри:

`-r` — рекурсивно додати каталог з усіма підкаталогами.  
`-e` — захистити архів паролем.  
`-u` — оновити вміст архіву (додати лише змінені файли).  
`-d` — видалити конкретний файл з архіву.

**Встановлення**

Більшість цих утиліт встановлена у системі за замовчуванням. За потреби встановити їх можна через стандартний пакетний менеджер:

```bash
sudo apt update
sudo apt install tar gzip bzip2 xz-utils zip unzip
```

> *Пакет `xz` знаходиться в `xz-utils`; для розпакування zip-архівів також потрібен `unzip`.*

> **5.2. Три приклади архівування та стиснення різними командами.**

Зазвичай у Linux для резервного копіювання поєднують `tar` з утилітою стиснення в одну команду:

- Створення `.tar.gz`-архіву (стиснення через `gzip`):
```bash
tar czvf compressed.tar.gz directory1
```

- Створення `.tar.bz2`-архіву (стиснення через `bzip2`):
```bash
tar cjvf bzipcompressed.tar.bz2 directory2
```

- Створення `.tar.xz`-архіву (стиснення через `xz`):
```bash
tar cJvf xzcompressed.tar.xz directory3
```

> **5.3. Яке призначення команд `cat`, `less`, `more`, `head`, `tail`? Опис і основні параметри. Як встановити.**

**1. Команда `cat` (Concatenate)**

Виводить вміст одного або кількох файлів на екран, а також дозволяє об'єднувати або створювати файли. Підходить для швидкого перегляду невеликих текстових файлів — якщо файл великий, текст просто прокрутиться до кінця.

Основні параметри:

`-n` — нумерувати всі рядки при виведенні.  
`-b` — нумерувати лише непорожні рядки.  
`-E` — позначати кінець кожного рядка символом `$`.  
`-s` — замінювати кілька порожніх рядків підряд одним.

**2. Команда `less`**

Сучасний посторінковий переглядач (pager) для великих текстових файлів. На відміну від `cat`, показує текст по одному екрану. Головна перевага — можливість прокручувати як вперед (Space / Page Down), так і назад (b / Page Up), а також те, що весь файл не завантажується у пам'ять одразу.

Основні параметри:

`-N` — відображати номери рядків.  
`-S` — обрізати довгі рядки (замість переносу на наступний рядок).  
`+F` — відстежувати нові записи у файлі (аналог `tail -f`).

**3. Команда `more`**

Більш старий попередник `less`. Виводить текст порційно по одному екрану, але функціонал обмежений — прокручування здебільшого лише вперед.

Основні параметри:

`-d` — показувати підказки для користувача і не подавати звуковий сигнал при помилках.  
`-c` — очищати екран перед виведенням кожної нової сторінки.  
`+num` — почати перегляд з рядка `num`.

**4. Команда `head`**

Виводить початкову частину файлу. За замовчуванням — перші 10 рядків. Зручно для швидкої перевірки структури або заголовку файлу.

Основні параметри:

`-n <кількість>` — вивести задану кількість рядків з початку (наприклад, `head -n 20 file.txt`).  
`-c <кількість>` — вивести задану кількість байтів з початку файлу.  
`-q` — не виводити заголовки з назвами файлів при обробці кількох файлів.

**5. Команда `tail`**

Виводить кінцеву частину файлу (за замовчуванням — останні 10 рядків). Дуже корисна для моніторингу лог-файлів, які постійно поповнюються.

Основні параметри:

`-n <кількість>` — вивести задану кількість рядків з кінця файлу.  
`-f` — відстежувати файл у реальному часі, відображаючи нові рядки в міру їх появи.  
`-c <кількість>` — вивести задану кількість байтів з кінця файлу.

**Встановлення**

Усі ці команди входять до базових пакетів `coreutils` та `less` і є частиною будь-якого стандартного дистрибутива Linux. У разі потреби:

```bash
sudo apt update
sudo apt install coreutils less
```

> *`cat`, `head`, `tail` входять до `coreutils`; `more` — зазвичай постачається з `util-linux` або `moreutils`.*

> **5.4. Принципи роботи командної оболонки з каналами, потоками та фільтрами.**

Командна оболонка Linux (наприклад, Bash) побудована на основі філософії Unix: кожна програма повинна вирішувати одне завдання, але робити це якісно, і мати змогу легко взаємодіяти з іншими програмами через стандартизовані інтерфейси.

**1. Потоки (Streams)**

При запуску будь-якої команди ОС автоматично відкриває три стандартні потоки даних:

- **stdin (0)** — стандартне введення. За замовчуванням — клавіатура.
- **stdout (1)** — стандартне виведення. За замовчуванням — екран термінала.
- **stderr (2)** — стандартне виведення помилок. Також за замовчуванням виводиться на екран, але в окремий потік, щоб помилки не змішувалися з корисним результатом.

Перенаправити ці потоки можна за допомогою спеціальних операторів:

- `>` — перенаправити `stdout` у файл (з перезаписом).
- `>>` — додати `stdout` у кінець файлу.
- `2>` — перенаправити `stderr` у файл.
- `2>&1` — об'єднати `stderr` з `stdout`.

**2. Канали (Pipes)**

Символ `|` використовується для з'єднання команд у конвеєр: `stdout` лівої команди стає `stdin` правої. Це дозволяє передавати дані між програмами безпосередньо в оперативній пам'яті, без створення тимчасових файлів.

Приклад: `cat myfile | grep student | wc -l` — зчитати файл, відфільтрувати рядки зі словом "student" і порахувати їхню кількість.

**3. Фільтри (Filters)**

Фільтр — це програма, яка читає дані зі `stdin`, якимось чином їх обробляє та виводить результат у `stdout`. Типові приклади: `grep` (пошук за шаблоном), `sort` (сортування), `wc` (підрахунок рядків/слів/символів).

Ці три концепції разом дозволяють будувати потужні ланцюжки обробки даних прямо в терміналі.

> **5.5. Яке призначення команди `grep`?**

Команда `grep` (Global Regular Expression Print) призначена для пошуку рядків у файлах або потоці даних, що відповідають заданому шаблону (слову, фразі або регулярному виразу). Рядки, які не збігаються з шаблоном, просто відкидаються. `grep` є ключовим інструментом-фільтром і часто використовується в конвеєрах для фільтрації великих обсягів даних — наприклад, пошуку конкретного процесу або помилки у лог-файлі.

Основні параметри:

`-i` — ігнорувати регістр (знаходить і "Error", і "error", і "ERROR").  
`-v` — інвертований пошук: виводити рядки, що НЕ містять шаблон.  
`-r` / `-R` — рекурсивний пошук у всіх підкаталогах.  
`-n` — виводити номер рядка перед кожним збігом.  
`-c` — вивести лише кількість рядків зі збігом, а не самі рядки.  
`-E` — розширений режим (підтримка складних регулярних виразів, аналог `egrep`).

**Встановлення:**

`grep` є базовою утилітою GNU та входить до складу практично будь-якого дистрибутива Linux. За потреби:

```bash
sudo apt update
sudo apt install grep
```

| `cut -d: -f1 /etc/passwd` | Виведення першого поля (імена користувачів) з `/etc/passwd` |
| `cut -d: -f1 /etc/passwd \| sort` | Виведення відсортованих імен користувачів |
| `cut -d: -f1 /etc/passwd \| sort \| more` | Посторінковий вивід відсортованих імен |
| `more /etc/passwd` | Посторінковий перегляд файлу `/etc/passwd` |
| `less /etc/passwd` | Перегляд файлу `/etc/passwd` через `less` |
| `head /etc/passwd` | Виведення перших 10 рядків файлу `/etc/passwd` |
| `tail /etc/passwd` | Виведення останніх 10 рядків файлу `/etc/passwd` |
| `head -2 /etc/passwd` | Виведення перших 2 рядків файлу |
| `ls /etc \| tail -5` | Виведення останніх 5 імен файлів у каталозі `/etc` |
| `head -n -20 /etc/passwd` | Виведення всіх рядків, крім останніх 20 |
| `grep sshd passwd` | Виведення рядків, що містять `sshd` |
| `grep '^root' passwd` | Виведення рядків, що починаються з `root` |
| `grep 'sync' passwd` | Виведення рядків з входженням `sync` у будь-якому місці |
| `grep 'sync$' passwd` | Виведення рядків, що закінчуються на `sync` |
| `grep '.y' passwd` | Пошук будь-якого символу перед літерою `y` |
| `grep 'sshd\|root\|operator' passwd` | Пошук одного із трьох шаблонів (потребує `-E`) |
| `grep -E 'sshd\|root\|operator' passwd` | Пошук кількох шаблонів у розширеному режимі |
| `egrep 'no(b\|n)' passwd` | Пошук рядків `nob` або `non` за допомогою `egrep` |
| `head passwd \| grep '[0-9]'` | Пошук рядків, що містять числові символи |
| `grep -E '[0-9]{3}' passwd` | Пошук рядків з трьома цифрами підряд (розширений режим) |

#### 4. Перенаправлення потоків виведення в Bash

| Команда | Що виконує |
| :--- | :--- |
| `cmd 1> file` | Перенаправляє `stdout` у файл із перезаписом; помилки залишаються на екрані |
| `cmd > file` | Те саме (дескриптор 1 є стандартним і може не вказуватись) |
| `cmd 2> file` | Перенаправляє `stderr` у файл; результат успішної роботи виводиться на екран |
| `cmd >> file` | Додає `stdout` у кінець файлу (без перезапису) |
| `cmd &> file` | Перенаправляє і `stdout`, і `stderr` у файл із перезаписом |
| `cmd > file 2>&1` | Класичний еквівалент попередньої команди: спочатку `stdout` у файл, потім `stderr` туди ж |
| `cmd >> file 2>&1` | Додає і `stdout`, і `stderr` у кінець файлу |
| `cmd 2>&1 > /dev/null` | `stderr` залишається на екрані, а `stdout` знищується (`/dev/null`) |
| `cmd 2> /dev/null` | Приховує всі помилки; стандартне виведення відображається на екрані |
| `cmd1 \| cmd2` | `stdout` команди `cmd1` передається як `stdin` команді `cmd2` |
| `cmd1 2>&1 \| cmd2` | І `stdout`, і `stderr` команди `cmd1` передаються у `stdin` команди `cmd2` |

#### 5. Пояснення прикладів перенаправлення потоків

| Команда | Що виконує | Тип перенаправлення |
| :--- | :--- | :--- |
| `echo "It is a new story." > story` | Записує рядок у файл `story`; якщо файл існує — перезаписує | `stdout` у файл з перезаписом (`>`) |
| `date > date.txt` | Записує поточну дату та час у файл `date.txt` | `stdout` у файл з перезаписом (`>`) |
| `cat file1 file2 file3 > bigfile` | Об'єднує три файли і зберігає результат у `bigfile` | `stdout` у файл з перезаписом (`>`) |
| `ls -l >> directory` | Додає деталізований список файлів у кінець файлу `directory` | Додавання `stdout` у файл (`>>`) |
| `sort < file1_unsorted > file2_sorted` | Сортує рядки з `file1_unsorted` і зберігає у `file2_sorted` | Введення з файлу (`<`) та виведення у файл (`>`) |
| `find -name '*.txt' > file.txt 2> /dev/null` | Знаходить `.txt`-файли, зберігає список у `file.txt`, помилки ігноруються | `stdout` у файл (`>`), `stderr` у `/dev/null` (`2>`) |
| `cat file1_unsorted \| sort > file2_sorted` | Читає файл, сортує через pipe і зберігає результат | Канал (`\|`) + перенаправлення `stdout` у файл (`>`) |
| `cat myfile \| grep student \| wc -l` | Читає файл, фільтрує рядки з "student" і рахує їх | Два канали (`\|`) для послідовної передачі даних між командами |

### Контрольні запитання

**1. Порівняльна характеристика процесів стиснення та архівування.**

Архівування — це об'єднання кількох файлів в один із збереженням структури каталогів, прав доступу та метаданих. Стиснення — застосування математичних алгоритмів для зменшення розміру файлу. На практиці ці процеси зазвичай поєднують: спочатку `tar` збирає файли в архів, а потім до нього застосовується стиснення.

**2. Інші утиліти для архівування та стиснення в Linux.**

Крім розглянутих інструментів, поширеними є: `7z` (програма `p7zip`) — забезпечує надзвичайно高кий ступінь стиснення завдяки власному алгоритму LZMA, а також `rar` / `unrar` — для роботи з пропрієтарним форматом RAR, широко поширеним у Windows.

**3. Порівняння алгоритмів стиснення.**

- **DEFLATE** (`gzip`) — найшвидший, мінімальне споживання ресурсів, середній ступінь стиснення.
- **Burrows-Wheeler** (`bzip2`) — стискає краще за `gzip`, але повільніший і вимагає більше пам'яті.
- **LZMA2** (`xz`) — найвищий ступінь стиснення, найповільніший і найбільш ресурсоємний процес, але розпакування відносно швидке.

**4. Утиліти архівування для мобільного телефону.**

На сучасних смартфонах (Android та iOS) базова підтримка ZIP вбудована у стандартні файлові менеджери. Для розширеної роботи з різними форматами використовуються сторонні додатки: ZArchiver, RAR (від RARLAB) або iZip.

**5. Утиліти архівування в ОС Windows.**

Windows має вбудовану підтримку ZIP через Провідник. Серед популярних сторонніх рішень — WinRAR (комерційний, підтримує RAR та ZIP) та 7-Zip (безкоштовний, з відкритим кодом, формат 7z забезпечує відмінний ступінь стиснення).

**6. Застосування архівування для резервного копіювання та адміністрування.**

Архівування з подальшим стисненням дозволяє зберегти всі необхідні дані в компактному вигляді в одному файлі. У системному адмініструванні це використовується для резервування конфігурацій, економії дискового простору, зменшення обсягу трафіку при передачі файлів по мережі, а також при розповсюдженні програмного забезпечення.

**7. Призначення `/dev/null`.**

`/dev/null` — спеціальний віртуальний пристрій у Linux, відомий як «чорна діра». Будь-які дані, перенаправлені туди, безслідно знищуються. Використовується для приховування небажаного виведення команд або повідомлень про помилки, коли вони не потрібні.
